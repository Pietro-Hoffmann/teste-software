# Software Testing — Calculator

A small calculator exercised by a unit test suite. The point of the repository isn't the
calculator — it's the tests: covering the happy path, boundary values and the error cases
a naive implementation misses, such as division by zero.

## Stack

**JavaScript** · **Jest**

## Running the tests

```bash
cd calculadora-testes
npm install
npm test
```

> Built for a software testing course.
